# Formatação de Último Nome (Citação)

## Descrição
Programa que recebe um nome completo fornecido pelo usuário e realiza a formatação no padrão bibliográfico clássico de citação (`ÚltimoNome, PrimeiroNome`).

O processamento identifica o primeiro e o último nome percorrendo os espaços da string e imprime o resultado utilizando aritmética de ponteiros.

## Exemplo
- **Entrada:**
  ```text
  Lucas Silva
  ```
- **Saída:**
  ```text
  Silva, Lucas
  ```
