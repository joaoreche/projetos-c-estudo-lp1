# Atividade Prática - String 2

## Instruções
Desenvolver um programa em C que receba uma frase do usuário e torne **maiúscula** a primeira letra de cada palavra, exceto para preposições e conjunções (`"de"`, `"do"`, `"da"`, `"e"`). 

O programa deve ser implementado com pelo menos uma função (além da função `main`) para executar algum processamento.

## Exemplo de Entrada e Saída
- **Entrada:**
  ```text
  aula de programacao em c
  ```
- **Saída:**
  ```text
  Aula de Programacao Em C
  ```
