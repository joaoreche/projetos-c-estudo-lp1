# Atividade Prática - String 1

## Instruções
Desenvolver um programa em C que receba uma frase do usuário e inverta cada palavra da frase, mantendo a ordem das palavras original. 

Você deve criar pelo menos uma função para realizar algum processamento.

## Exemplo de Entrada e Saída
- **Entrada:**
  ```text
  Aula de programacao em C
  ```
- **Saída:**
  ```text
  aluA ed oacamargorp me C
  ```
