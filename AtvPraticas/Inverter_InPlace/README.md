# Inversão de String In-Place

## Descrição
Implementação de algoritmo para inverter uma string *in-place* (modificando o próprio vetor em memória, sem a necessidade de criar um vetor auxiliar).

O algoritmo utiliza dois ponteiros (`inicio` e `fim`): o ponteiro `fim` é posicionado no último caractere válido da string, e um loop realiza a troca dos valores apontados enquanto os ponteiros convergem em direção ao centro da cadeia.

## Exemplo
- **Entrada:**
  ```text
  Linguagem C
  ```
- **Saída:**
  ```text
  C megaugniL
  ```
