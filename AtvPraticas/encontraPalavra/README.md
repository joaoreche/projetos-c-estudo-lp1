# Encontrar Palavra em Frase

## Descrição
Programa que solicita ao usuário uma frase e uma palavra-chave para busca.

Utiliza aritmética de ponteiros e a função `strstr` da biblioteca `<string.h>` para rastrear a frase e calcular o número total de ocorrências da palavra buscada.

## Exemplo
- **Entrada:**
  - Frase: `o doce de batata doce eh mais doce que o doce`
  - Palavra: `doce`
- **Saída:**
  - `Qnte de doce: 4`
