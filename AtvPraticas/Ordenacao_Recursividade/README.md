# Ordenação e Pesquisa Binária com Structs

## Descrição
Atividade prática integrando múltiplos conceitos fundamentais da disciplina: **Registros (`struct`)**, **Algoritmos de Ordenação** e **Recursividade**.

O programa gerencia uma base de dados de alunos definida pelo tipo `TipoAluno` contendo RA, nome, quantidade de faltas e nota final.

## Funcionalidades
1. **`OrdenaAlunos`**: Ordenação alfabética pelo nome dos alunos utilizando o método da bolha (*Bubble Sort*) e `strcmp`.
2. **`CalculaMedia`**: Função que calcula e retorna a média aritmética das notas da turma.
3. **`OrdenarPorRA`**: Ordenação dos alunos em ordem crescente pelo número de RA.
4. **`PesquisaBinaria`**: Implementação recursiva do algoritmo de busca binária para localizar um aluno a partir de seu RA no vetor previamente ordenado.
